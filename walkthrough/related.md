# Free Zovo extensions for the other files of an app project

- Git Commit Graph shows the branches and merges of your repository.
- SVG Preview & Viewer shows the SVG files of app icons and asset catalogs beside the editor and exports PNG.
- JSON Tree Viewer opens large JSON files, such as Package.resolved and asset catalog Contents.json, as a searchable tree.

Each link opens the extension page. Nothing installs until you click Install there.
